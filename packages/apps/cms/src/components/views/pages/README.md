# نظام إدارة الصفحات مع الوحدات

## نظرة عامة

تم تطوير نظام شامل لإدارة الصفحات يدعم:
- إنشاء وتعديل الصفحات
- اختيار الوحدات (Modules) مع دعم الاختيار المتعدد
- ترتيب الوحدات باستخدام Drag & Drop
- دعم الوحدات من نوع Singleton مع إمكانية تكوين القيم
- التحقق من صحة البيانات والتحقق من القواعد

## المكونات الرئيسية

### 1. أنواع البيانات (Types)
- `IPage`: واجهة الصفحة الأساسية
- `IPageModule`: واجهة وحدة الصفحة
- `IModule`: واجهة الوحدة
- `IModuleInput`: واجهة حقول الوحدة

### 2. المكونات (Components)

#### `CreateUpdatePageView`
المكون الرئيسي لإنشاء وتعديل الصفحات:
- نموذج إدخال بيانات الصفحة الأساسية
- دمج مكون اختيار الوحدات
- التحقق من صحة البيانات
- إنشاء slug تلقائياً من العنوان

#### `ModuleSelector`
مكون اختيار وترتيب الوحدات:
- عرض قائمة Available units
- دعم الاختيار المتعدد
- Drag & Drop لإعادة الترتيب
- دعم خاص للوحدات Singleton
- إمكانية تكوين قيم الوحدات

#### `ModuleFieldsForm`
نموذج تكوين حقول الوحدات:
- دعم أنواع مختلفة من الحقول
- التحقق من صحة البيانات
- واجهة سهلة الاستخدام

#### `ModulePreview`
معاينة Selected units:
- عرض تفاصيل الوحدات
- إظهار القيم المكونة
- معلومات الترتيب

### 3. الخدمات (Services)

#### `modules.ts`
خدمات API للوحدات:
- `getModules()`: جلب جميع الوحدات
- `getModuleById()`: جلب وحدة محددة
- `getModuleInputs()`: جلب حقول الوحدة

#### `pages.ts`
خدمات API للصفحات:
- `getPages()`: جلب جميع الصفحات
- `getPageById()`: جلب صفحة محددة
- `createPage()`: Create a new page
- `updatePage()`: تحديث صفحة موجودة
- `deletePage()`: حذف صفحة

### 4. الأدوات المساعدة (Utils)

#### `pageValidation.ts`
أدوات التحقق من صحة البيانات:
- `validatePageData()`: التحقق من بيانات الصفحة
- `sanitizeSlug()`: تنظيف Short link
- `generateSlugFromTitle()`: إنشاء slug من العنوان

### 5. Hooks المخصصة

#### `useModules.ts`
Hook لإدارة حالة الوحدات:
- تحميل الوحدات
- إدارة حالة التحميل والأخطاء
- إعادة التحميل

## الميزات الرئيسية

### 1. دعم الوحدات Singleton
- الوحدات من نوع Singleton يمكن إضافتها مرة واحدة فقط
- تتطلب تكوين قيم الحقول عند الإضافة
- عرض مؤشر بصري للتمييز

### 2. Drag & Drop
- إعادة ترتيب الوحدات بسهولة
- واجهة بصرية واضحة
- حفظ الترتيب تلقائياً

### 3. التحقق من صحة البيانات
- التحقق من البيانات الأساسية
- التحقق من قواعد الوحدات
- عرض رسائل خطأ وتحذير واضحة

### 4. واجهة مستخدم محسنة
- تصميم responsive
- رسائل تفاعلية
- مؤشرات بصرية واضحة

## كيفية الاستخدام

### Create a new page
1. انتقل إلى `/admin/pages/create`
2. أدخل Page title (سيتم إنشاء slug تلقائياً)
3. اختر الوحدات المطلوبة
4. رتب الوحدات حسب الحاجة
5. كون قيم الوحدات Singleton
6. احفظ الصفحة

### تعديل صفحة موجودة
1. انقر على زر التعديل في جدول الصفحات
2. عدل البيانات المطلوبة
3. أضف أو احذف الوحدات
4. أعد ترتيب الوحدات إذا لزم الأمر
5. احفظ التغييرات

## التكوين

### إضافة نوع حقل جديد
1. أضف النوع إلى `EnInputType` في `module-input.ts`
2. أضف معالج الحقل في `ModuleFieldsForm.tsx`
3. اختبر النوع الجديد

### تخصيص التحقق من صحة البيانات
عدل الدوال في `pageValidation.ts` لإضافة قواعد جديدة.
